# Mes Sorties Resto — site officiel

Site statique de présentation de l’application iPhone **Mes Sorties Resto**.

## Structure

- `index.html` : page publique complète
- `assets/styles.css` : mise en page responsive pour ordinateur et iPhone
- `assets/app-icon.png` : icône de l’application
- `assets/screen-*.png` : captures réelles utilisées dans la présentation
- `assets/og-v2.jpg` : aperçu utilisé lors du partage du lien

Le site est automatiquement publié par GitHub Pages après chaque modification de la branche `main`.

Lorsque la fiche App Store sera disponible, il faudra remplacer les boutons « Bientôt disponible » par son URL officielle.
