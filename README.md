# Mes Sorties Resto — site officiel

Landing page française de l’application iPhone **Mes Sorties Resto**.

Le site présente les fonctions principales de l’application, son approche respectueuse de la vie privée et la différence entre la version gratuite et la Version complète à achat unique.

## Développement

Prérequis : Node.js `>=22.13.0`.

```bash
npm install
npm run dev
npm run build
```

Le bouton App Store est volontairement indiqué comme « bientôt disponible ». Lorsque la fiche App Store sera publiée, il suffira de remplacer son ancre dans `app/page.tsx` par l’URL officielle.
